# BrainQuiz - Quiz Game

*BrainQuiz* هو لعبة أسئلة رياضية ممتعة، تتيح لك اختبار مهاراتك في الحساب الذهني بسرعة ودقة.  
اللعبة تحتوي على مستويات صعوبة مختلفة، مؤقت زمني لكل سؤال، وحفظ نتائج كل اختبار مع التاريخ والوقت السوري.

---

## مميزات المشروع

- أسئلة رياضية تلقائية (جمع، طرح، ضرب، قسمة)  
- مستويات صعوبة: سهل، متوسط، صعب، أو مختلط  
- مؤقت لكل سؤال لإضافة تحدي وحماس  
- حفظ نتائج اللاعب في ملف نصي مع التاريخ والوقت السوري  
- استخدام vector لتخزين الأسئلة والنتائج  
- واجهة نصية بسيطة وسهلة الاستخدام  

---

## طريقة التشغيل

1. قم بتحميل أو نسخ ملفات المشروع إلى جهازك.  
2. افتح المشروع باستخدام أي محرر C++ أو IDE مثل Visual Studio، Code::Blocks أو Dev C++.  
3. قم بترجمة المشروع وتشغيله.  
4. اتبع التعليمات على الشاشة:  
   - اختيار عدد الأسئلة  
   - اختيار مستوى الصعوبة  
   - اختيار نوع العمليات الحسابية  
   - الإجابة على الأسئلة ضمن الوقت المحدد
